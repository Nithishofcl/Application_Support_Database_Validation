Database Connectivity & Data Validation Checks

Project: Application Support L1 Mini Project

Tools: Oracle SQL Developer, SQL

Description

This project demonstrates SQL-based database validation and troubleshooting for Application Support. It identifies failed transactions, missing values, and duplicate transaction IDs using SQL queries.

Skills Learned

- SQL queries and data validation
- Database troubleshooting
- Error investigation and documentation

Files

- "sample_data.sql" – Creates a table and inserts sample data.
- "validation_queries.sql" – Contains SQL validation queries.
- "troubleshooting_report.md" – Documents findings and recommendations.
